# Temporal constraint design

The single nondeterministic boundary compiles meaning, direction and units. A validator independently regenerates every bound from the original input and agrees on stable fields only. All feasibility, proof, range and certification logic is deterministic. Keeping original normalized rule text beside each bound makes interpretation inspectable without trusting generated quotations.

Integer constants define a standard difference-constraint system. Feasible potentials are integral, so the returned witness meets the minute-resolution model. Tight per-event bounds are not independent choices. The horizon is an explicit part of the problem, and can itself cause inconsistency.

The API is intentionally immutable and bounded. Correcting a rule creates a fresh record. Public proof consumers must verify chain, source/protocol, finalized status and the full content digest before acting.
